# ИНТЕРЬЕР — интернет-магазин освещения
Next.js 15 · React 19 · TypeScript · Tailwind 3 · App Router.
    npm install && npm run dev      # разработка
    npm run build && npm start      # продакшен
Данные: `data/seed.json` → `data/products.ts`. Фото товаров: `public/images/products/<slug>-off|on.jpg`, оригиналы — `originals/products/`.
Деплой: импортируйте репозиторий в Vercel. Сайт вручную ещё не собирался — запустите `npm run build` и поправьте вывод.

## Страницы
- `/` — главная с каталогом (фильтры в URL: `?category=&q=&color=&material=&min=&max=&badge=&sort=`). На телефоне фильтры открываются выдвижной панелью.
- `/catalog/[slug]` — общий шаблон страницы товара (галерея, характеристики, хлебные крошки, связь с менеджером). Несуществующий slug → 404.
- `/installment` — исламская рассрочка. Условия выводятся только при `confirmed: true` в `data/installment.ts`.

## Данные
Все страницы получают товары через `lib/catalog` (локальный источник или внешний API, см. `docs/catalog-api.md`).
Контакты и интеграции — только через переменные окружения (`.env.example`).

## Фото и логотип
Фото товаров: `public/images/products/<slug>-off.jpg` и `<slug>-on.jpg` (4:5, 1000×1250). Чтобы добавить товар — строка в `data/seed.json` + два файла. Категории без товаров скрываются автоматически.
Заставка: `public/logo-anim.png` (анимированный APNG, играет один раз), статичный логотип — `public/logo.png`.

## Логотип
Варианты лежат в `public/logo-variants/` (откройте `preview.html`). Активный вариант выбирается в `lib/site.ts` (`LOGO_NAME`: `red-1`, `red-2` или `gold`).

## Новое
- **Поиск по фото**: кнопка в строке поиска. Сравнивает цвета и композицию загруженного кадра с фото товаров (в браузере, без ИИ, демо-режим). Для точного поиска по форме нужен сервис на бэкенде — см. `docs/visual-search.md`. После замены фото подписи в `data/signatures.json` нужно пересчитать.
- **Помощь менеджера**: плавающая кнопка. Заявки уходят в Telegram: задайте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` (см. `.env.example`); телефон, WhatsApp и Telegram — переменные `NEXT_PUBLIC_MANAGER_*`.
- **Водяной знак**: на сайте фото чистые. Когда покупатель жмёт «Скачать фото» на карточке, в файл внизу дописывается надпись «Лампарди» (параметры — `lib/watermark.config.ts`, отрисовка — `lib/download.ts`). Сохранение правой кнопкой на карточках отключено; от скриншотов и инструментов разработчика это не защищает.
- **Розетки и выключатели**: категория с фото товаров в интерьере (выключен / включён).
- **Исламская рассрочка**: текст и условия в `data/installment.ts`.
- Категории «Лампы», «Прожекторы», «Карнизы и гардины», «Багеты» заведены в `data/categories.ts`; пока в них нет товаров, они скрыты из каталога и упоминаются только строкой «Скоро в ассортименте».
